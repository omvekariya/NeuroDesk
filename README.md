# NeuroDesk

AI-assisted service desk prototype, built in a 36-hour hackathon: automated ticket assignment that routes incoming requests to technicians based on skill and current workload, instead of manual triage.

## What it does
- Skill- and workload-aware assignment of incoming tickets
- Per-technician workload visibility
- AI-assisted request handling

## Tech stack
- Frontend: JavaScript, HTML, CSS
- AI backend: Python

*Hackathon prototype — built under a 36-hour deadline by a small team; rough edges intentional.*
